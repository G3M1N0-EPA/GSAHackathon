# Do Not Call

A watsonx Orchestrate agent that helps you register on the FTC Do Not Call Registry, identify TCPA violations, generate cease-and-desist emails, and get step-by-step guidance for filing complaints and pursuing civil remedies.

> **Full documentation coming soon.**

---

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `NUMVERIFY_API_KEY` | Optional | API key for Numverify phone lookup. If not set, the agent gracefully skips carrier lookup and provides manual lookup guidance instead. |
